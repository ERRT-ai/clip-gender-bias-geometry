# Notice

This repository contains research code for evaluating occupational gender association gaps in CLIP.

## Third-party assets

### FairFace
FairFace images and labels are obtained from the original FairFace distribution. They are not redistributed in this repository. Users must follow the dataset's original terms, license and responsible-use requirements.

### OpenAI CLIP
The project uses OpenAI CLIP. CLIP code and pretrained weights remain subject to their original license and terms.

## Research scope

The repository studies sensitivity of a specific CLIP bias measurement to evaluation-pool composition, prompt formulation and embedding geometry. It should not be used as a standalone fairness certification or as evidence that a model is free of demographic bias.
